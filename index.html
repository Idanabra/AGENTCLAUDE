SAP Sales Cloud connector

Connect Claude to your SAP Sales Cloud V2 system. The connector only reads data from SAP.

  1. Unlock settings

    Enter the access token set as MCP_TOKEN on the server.

  2. SAP connection

    The connector uses these details for every request to SAP. Only GET requests are sent.

    Only the address of the system, without /sap/c4c/api.
    Stored on the connector server, never shown again.

    Connection check per SAP service

  3. Add it to Claude

    Copy this address into claude.ai as a custom connector. It contains your access token, so share it only with people who may read the SAP data.

    1. In claude.ai open Settings → Connectors → Add custom connector and paste the URL.
    2. Create a Project and paste the project instructions from the repository.
    3. In a chat in the project, turn the connector on from the tools menu and ask, for example: מי קנה מוצרים מקבוצת משאבות?
Credentials are kept on the connector server and are never sent back to this page.
